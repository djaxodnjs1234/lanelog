# 레인로그 (LaneLog)

한 레인씩 쌓아 가는 나의 수영 기록. 수영을 마치고 1분 안에 기록하고, 한 주를 돌아보고, 다음 주에 집중할 연습을 정하는 모바일 우선 웹 앱입니다. 안드로이드 Chrome에서 홈 화면에 설치하면 일반 앱처럼 열리고, 인터넷이 없어도 기록할 수 있습니다.

## 주요 기능

- **빠른 기록**: 영법별 거리를 +/− 버튼(25m 단위)으로 입력하면 총 거리와 25m 반복 횟수가 자동 계산됩니다. ‘평소 루틴’ 버튼 한 번으로 채울 수도 있습니다.
- **물속에서 느낀 점**: 자유형 호흡·다리 가라앉음·발차기 타이밍, 어려웠던 점, 메모, 통증·불편함(입력하면 ‘확인 필요’로 표시)
- **홈**: 오늘 기록 여부, 이번 주 거리와 요일별 그래프, 지난주 복기에서 정한 ‘이번 주 집중 연습’
- **주간 복기**: 지난주 대비 수치, 한 주 돌아보기, 세 가지 핵심 항목의 변화, 다음 주 집중 연습(자동 저장)
- **기록 목록**: 검색, 상태·항목 필터, 월별 묶음
- **기기 간 동기화**: 본인 GitHub의 비공개 저장소를 저장소로 사용해 휴대폰과 PC가 같은 기록을 봅니다.
- **안전장치**: 작성 중인 기록 자동 임시 저장, 삭제 되돌리기, JSON 백업/가져오기, 다크 모드

## 휴대폰에 설치하기 (안드로이드)

1. Chrome으로 배포 주소(`https://<GitHub 아이디>.github.io/lanelog/`)를 엽니다.
2. 홈의 **설치** 버튼, 또는 Chrome 메뉴(⋮) › **홈 화면에 추가**를 누릅니다.
3. 앱 아이콘을 길게 누르면 ‘연습 기록하기’, ‘주간 복기’ 바로가기가 있습니다.

## 휴대폰과 PC 동기화 (GitHub)

GitHub Pages는 정적 파일만 제공하므로, 기록은 각 기기에 저장되고 **본인 GitHub의 비공개 저장소에 있는 JSON 파일 하나**로 기기끼리 맞춥니다. 서버나 별도 회원가입이 필요 없습니다.

1. 비공개 저장소 `lanelog-data`를 만듭니다.
2. [Fine-grained 토큰](https://github.com/settings/personal-access-tokens/new)을 만듭니다.
   - Repository access: **Only select repositories** › `lanelog-data`
   - Permissions › Repository › **Contents: Read and write**
3. 앱의 **설정 › 기기 간 동기화 › GitHub 동기화 설정하기**에 아이디·저장소 이름·토큰을 입력합니다.
4. 두 번째 기기는 첫 기기의 **설정 › 다른 기기 연결**에 뜨는 QR을 휴대폰 카메라로 스캔하면 바로 연결됩니다.

동작 방식

- 기록을 저장하면 몇 초 뒤, 앱을 다시 열 때, 인터넷이 다시 연결될 때 자동으로 동기화합니다.
- 두 기기에서 동시에 고쳐도 기록 단위로 병합합니다(같은 기록은 마지막으로 고친 쪽, 삭제는 삭제 이후에 고치지 않은 경우에만 반영).
- 동기화할 때마다 저장소에 커밋이 남으므로 GitHub에서 이전 버전을 확인하고 되돌릴 수 있습니다.
- 토큰은 그 기기의 브라우저 저장소에만 저장되며 `api.github.com` 외에는 전송하지 않습니다. 토큰은 `lanelog-data` 저장소 하나만 접근하도록 만드세요.

## 이전 Swimnote에서 옮기기

Swimnote의 **기록 내보내기**로 받은 JSON 파일을 레인로그 **설정 › 백업 › 가져오기**로 불러오면 지금 기록과 합쳐집니다.

## 개발

외부 패키지 없이 바닐라 JavaScript(ES 모듈)로 작성되어 빌드 단계가 없습니다. Node.js 20 이상이 필요합니다.

```sh
npm run dev            # http://127.0.0.1:5173
npm run dev -- --host  # 같은 와이파이의 휴대폰에서 확인 (http라 오프라인 기능은 꺼짐)
npm test               # 데이터 모델·병합·GitHub 동기화 테스트
```

| 파일 | 내용 |
| --- | --- |
| `web/index.html`, `web/style.css` | 화면 골격과 스타일 (모바일 우선, 900px 이상은 왼쪽 메뉴) |
| `web/app.js` | 화면, 입력, 자동 저장, 안드로이드 뒤로 가기, 동기화 일정 |
| `web/store.js` | 데이터 모델, 정규화, 기기 간 병합, 통계, 백업 |
| `web/sync.js` | GitHub Contents API 동기화, 연결 링크 |
| `web/qr.js` | 다른 기기 연결용 QR 코드 생성기 |
| `web/sw.js`, `web/manifest.webmanifest` | 오프라인 사용과 홈 화면 설치(PWA) |

## 배포 (GitHub Pages)

`main` 브랜치에 푸시하면 `.github/workflows/deploy.yml`이 테스트를 실행한 뒤 `web/` 폴더를 GitHub Pages에 배포합니다. 처음 한 번 저장소의 **Settings › Pages › Source**를 **GitHub Actions**로 설정해야 합니다. 배포할 때 커밋 해시가 버전으로 들어가며, 설치된 앱은 다음 실행 때 ‘새 버전이 준비됐어요’ 알림을 띄웁니다.
